# Fuentes Tipográficas para ClickTranslate

Este directorio almacena las fuentes TrueType (.ttf) recomendadas para la re-tipografía de mangas, manhwas y cómics:

1. **Globos de Diálogo:**
   - `AnimeAce.ttf` (o `animeace.ttf`)
   - `WildWords.ttf` (o `wildwords.ttf`)

2. **Onomatopeyas / SFX:**
   - `Impact.ttf` (o `impact.ttf`)
   - `Bangers.ttf`

> [!NOTE]
> Si este directorio no contiene estas fuentes, el motor de tipos (`typesetter.py`) utilizará automáticamente fuentes del sistema (ej. Arial, Segoe UI, Tahoma) sin interrumpir el proceso.
